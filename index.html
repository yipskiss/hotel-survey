Hotel 360° Survey — Test Page

Researcher only — verify all panoramas before launching the survey

Setup instructions: Place your 360° equirectangular images in the /images/ folder. File naming convention: hotel_01_lobby.jpg, hotel_01_room.jpg, etc. Then click each button below to verify the panorama loads correctly.

Qualtrics Embed Code

Copy this iframe code into a Qualtrics question (HTML mode). Replace the URL with your GitHub Pages URL and the image filename.

// Qualtrics 질문 → HTML 편집 모드에서 붙여넣기 <iframe src="https://YOUR_USERNAME.github.io/survey/viewer.html?image=hotel_01_lobby.jpg" width="960" height="560" frameborder="0" allow="gyroscope" style="border-radius:10px; display:block; margin:0 auto;" ></iframe>

Tip: Each hotel/space gets its own Qualtrics page. Just change ?image=hotel_XX_lobby.jpg for each page.
